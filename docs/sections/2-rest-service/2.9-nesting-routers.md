# 2.9 - Nesting Multiple Routers

## Overview

Our `main.rs` now has 9 handler functions and is growing fast. As RustFlow adds users, comments, notifications, etc., a single file won't scale. Axum's **router nesting** lets us organize endpoints into separate modules, each with its own `Router`, and compose them in `main()`.

The key challenge is ensuring state flows correctly through nested routers.

## How Nesting Works

```text
Router::new()
    .route("/", get(root))                          → GET /
    .merge(health::router())                        → GET /health, GET /config
    .nest("/api/tasks", tasks::router())            → GET /api/tasks, POST /api/tasks, etc.
    .nest("/api/projects", projects::router())      → GET /api/projects, POST /api/projects, etc.
    .with_state(state)
```

There are two ways to compose routers:

| Method | Behavior | Use when |
|---|---|---|
| `.merge(router)` | Combines routes at the same level — no prefix added | Health checks, root-level routes |
| `.nest("/prefix", router)` | Adds a path prefix to all routes in the nested router | Domain routes (`/api/tasks`, `/api/projects`) |

### State and Nested Routers

**Critical rule:** When you call `.with_state(state)` on the outer router, it provides state to all merged and nested routers — **as long as their type signature matches**.

Each route module returns `Router<AppState>` (a router that *expects* `AppState` but doesn't have it yet). The outer router provides it via `.with_state()`.

```text
tasks::router()   → Router<AppState>  ← "I need AppState"
                                        │
.with_state(state) ────────────────────┘ "Here it is"
                                        │
                       Router<()>  ← "Fully resolved, ready to serve"
```

**If the types don't match, you get a compile error.** This is one of Axum's great strengths — mismatched state is caught at build time, not at runtime.

## Step 3: Create the Health Routes

**Create** `crates/rustflow-server/src/routes/health.rs`:

```rust name=crates/rustflow-server/src/routes/health.rs
use axum::{extract::State, routing::get, Json, Router};
use rustflow_common::AppConfig;

use crate::state::AppState;

/// GET /health
///
/// Returns service health information. Reads from `AppConfig`
/// which requires no lock (immutable after startup).
async fn health(State(state): State<AppState>) -> Json<serde_json::Value> {
    Json(serde_json::json!({
        "service": state.config.app_name,
        "version": state.config.version,
        "status": "ok",
    }))
}

/// GET /config
///
/// Returns the full application configuration (read-only, no lock needed).
async fn config(State(state): State<AppState>) -> Json<AppConfig> {
    Json(state.config.clone())
}

/// Build the health/meta router.
///
/// Uses `.merge()` in main (no prefix) so these become:
///   GET /health
///   GET /config
pub fn router() -> Router<AppState> {
    Router::new()
        .route("/health", get(health))
        .route("/config", get(config))
}
```

## Step 4: Create the Task Routes

This file contains all the task handlers that were previously in `main.rs`. The logic is identical — we're just moving it to its own module.

**Create** `crates/rustflow-server/src/routes/tasks.rs`:

```rust name=crates/rustflow-server/src/routes/tasks.rs
use axum::{
    extract::{Json, Path, State},
    http::StatusCode,
    routing::{get, patch},
    Router,
};
use rustflow_common::{CreateTask, Task, TaskFilter, TaskStatus};

use crate::extractors::{ValidatedJson, ValidatedQuery};
use crate::state::AppState;

/// GET /api/tasks?status=pending&priority=high&search=workspace
async fn list(
    State(state): State<AppState>,
    ValidatedQuery(filter): ValidatedQuery<TaskFilter>,
) -> Json<Vec<Task>> {
    let store = state.tasks.0.read().await;

    let filtered: Vec<Task> = store
        .tasks
        .iter()
        .filter(|task| filter.status.as_ref().map_or(true, |s| &task.status == s))
        .filter(|task| filter.priority.as_ref().map_or(true, |p| &task.priority == p))
        .filter(|task| {
            filter.search.as_ref().map_or(true, |s| {
                task.title.contains(s)
                    || task.description.as_ref().map_or(false, |d| d.contains(s))
            })
        })
        .cloned()
        .collect();

    Json(filtered)
}

/// GET /api/tasks/:id
async fn get_one(
    State(state): State<AppState>,
    Path(id): Path<u64>,
) -> Result<Json<Task>, StatusCode> {
    let store = state.tasks.0.read().await;

    store
        .tasks
        .iter()
        .find(|task| task.id == id)
        .cloned()
        .map(Json)
        .ok_or(StatusCode::NOT_FOUND)
}

/// POST /api/tasks
async fn create(
    State(state): State<AppState>,
    ValidatedJson(payload): ValidatedJson<CreateTask>,
) -> (StatusCode, Json<Task>) {
    let mut store = state.tasks.0.write().await;

    let task = Task {
        id: store.next_id,
        title: payload.title,
        description: payload.description,
        priority: payload.priority,
        status: TaskStatus::Pending,
    };

    store.next_id += 1;
    store.tasks.push(task.clone());

    (StatusCode::CREATED, Json(task))
}

/// PUT /api/tasks/:id
async fn update(
    State(state): State<AppState>,
    Path(id): Path<u64>,
    ValidatedJson(payload): ValidatedJson<CreateTask>,
) -> Result<Json<Task>, StatusCode> {
    let mut store = state.tasks.0.write().await;

    if let Some(task) = store.tasks.iter_mut().find(|task| task.id == id) {
        task.title = payload.title;
        task.description = payload.description;
        task.priority = payload.priority;
        Ok(Json(task.clone()))
    } else {
        Err(StatusCode::NOT_FOUND)
    }
}

/// DELETE /api/tasks/:id
async fn delete(
    State(state): State<AppState>,
    Path(id): Path<u64>,
) -> StatusCode {
    let mut store = state.tasks.0.write().await;

    let len_before = store.tasks.len();
    store.tasks.retain(|task| task.id != id);

    if store.tasks.len() < len_before {
        StatusCode::NO_CONTENT
    } else {
        StatusCode::NOT_FOUND
    }
}

/// PATCH /api/tasks/:id/status
async fn change_status(
    State(state): State<AppState>,
    Path(id): Path<u64>,
    Json(payload): Json<TaskStatus>,
) -> Result<Json<Task>, StatusCode> {
    let mut store = state.tasks.0.write().await;

    if let Some(task) = store.tasks.iter_mut().find(|task| task.id == id) {
        task.status = payload;
        Ok(Json(task.clone()))
    } else {
        Err(StatusCode::NOT_FOUND)
    }
}

/// Build the tasks router.
///
/// Mounted with `.nest("/api/tasks", ...)` in main so these become:
///   GET    /api/tasks
///   POST   /api/tasks
///   GET    /api/tasks/:id
///   PUT    /api/tasks/:id
///   DELETE /api/tasks/:id
///   PATCH  /api/tasks/:id/status
pub fn router() -> Router<AppState> {
    Router::new()
        .route("/", get(list).post(create))
        .route("/{id}", get(get_one).put(update).delete(delete))
        .route("/{id}/status", patch(change_status))
}
```

## Step 6: Compose Everything in Main

**Update** `crates/rustflow-server/src/main.rs` — replace the entire file. Changes from 2.7 are:
- Removed all handler functions (moved to `routes/` modules)
- Added `mod routes;`
- Used `.merge()` for health routes and `.nest()` for domain routes
- Only the `root` handler remains in `main.rs`

```rust name=crates/rustflow-server/src/main.rs
use axum::{routing::get, Router};
use rustflow_common::{APP_NAME, APP_VERSION};
use tokio::net::TcpListener;

mod extractors;
mod routes;
mod state;

use state::AppState;

/// Root endpoint — simple liveness check.
async fn root() -> &'static str {
    "RustFlow is running!"
}

#[tokio::main]
async fn main() {
    let state = AppState::new();

    let app = Router::new()
        // Root liveness
        .route("/", get(root))
        // Health & config — merged at root level (no prefix)
        .merge(routes::health::router())
        // Domain routes — nested under /api/*
        .nest("/api/tasks", routes::tasks::router())
        .nest("/api/projects", routes::projects::router())
        // Provide state to ALL routes (merged and nested)
        .with_state(state);

    let addr = "0.0.0.0:3000";
    let listener = TcpListener::bind(addr)
        .await
        .expect("Failed to bind to address");

    println!("{} v{} listening on {}", APP_NAME, APP_VERSION, addr);

    axum::serve(listener, app)
        .await
        .expect("Server error");
}
```
